Scope
=====


This Technical Report analyses behavioural guardrails for agentic AI from the system side, with emphasis on safety and security for cyber-physical systems. It addresses the risks created when an autonomous agent acts on tools, application programming interfaces, data, other agents and physical plant, and the controls by which those risks can be bounded. The object of protection is the external <span class="mark">cyber-physical system</span>, not the agent, its model or its provider's infrastructure. Safety concerns harm to persons and physical assets from agent action; security concerns adversarial compromise of the agent or its supply chain converted into harm to the external <span class="mark">cyber-physical system</span>. The report does not address protection of the agent itself, except where that protection bounds the risk the agent poses.

<span class="mark">The scope includes:</span>

\- The characterisation of system-facing behavioural risks, and of the attack surfaces through which they arise;

\- The current state of the art, industrial practice and reported results;

\- The development trends expected to shape the next three to five years;

\- The assessment factors and the collection methods by which the effectiveness of a guardrail deployment is judged;

\- A general, vendor-neutral assessment framework for behavioural guardrails in agentic AI for cyber-physical systems, including deterministic, in-deadline and fail-closed enforcement;

\- The elements that appear standardizable.

The Technical Report is addressed to standards developers, integrators, operators and regulators concerned with agentic AI in cyber-physical systems.
